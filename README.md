# dockprom-ai
Dockprom-AI is an out-of-the-box observability and AIOps stack for Docker hosts, containers, and LLMs. It pairs Prometheus, Grafana, Loki, Tempo, and OpenTelemetry with Logporter, host Ollama via Envoy, native Grafana/Prometheus MCP servers, Keep AIOps, Mattermost, and pgvector RAG with Chainlit and Generative UI
